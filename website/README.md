# Local marketing website

Buildless static HTML, CSS and original SVG artwork. Generated by `python tools/prepare_release.py`; outputs are in `website/dist`. No external libraries, fonts, analytics or form submissions. Serve locally with `python -m http.server 8080 --directory website/dist`.

Before deployment, set an owned HTTPS domain with `python tools/prepare_release.py --base-url https://YOUR-DOMAIN`, review product claims and privacy notice, add the verified Amazon listing link, configure a real support route and complete localisation. The default `.invalid` domain is deliberately non-production and pages are noindex. Hreflang entries cover only the actual English page; no untranslated locale pages are invented. No live launch or purchase offer is claimed.

The friendly house/capsule/rounded shape artwork is original SVG source, not an app screenshot. The site has not been published.
